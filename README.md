# Список покупок

Учебное приложение на React: добавление и удаление товаров, подсчёт общей стоимости.

## Запуск

```powershell
git clone https://github.com/sagakri/react-list.git
cd react-list
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале. Если зависимости уже установлены в родительской папке `REACT`, можно сразу выполнить `npm run dev`.

## Как выполнено задание

- `App.jsx`: `useState` хранит массив товаров и значения полей формы. `setItems` добавляет и удаляет товары без изменения исходного массива.
- `ShoppingItem.jsx`: отдельный компонент одного товара. Получает товар (`item`) и функцию удаления (`onRemove`) через props.
- `map` отображает товары, `filter` удаляет товар по идентификатору, `reduce` вычисляет общую стоимость.
- Название обязательно; цена указывается в кыргызских сомах с точностью до тыйынов. После добавления поля очищаются.

Список хранится в памяти и сбрасывается после перезагрузки страницы.

Проверка сборки: `npm run build`.
